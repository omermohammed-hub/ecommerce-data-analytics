# E-Commerce Data Analytics Project

## Project Overview

This project analyses e-commerce sales and customer data to identify
revenue trends, customer behaviour, product performance and business
opportunities.

## Objectives

- Analyse sales and revenue trends
- Identify high-performing products and categories
- Analyse customer purchasing behaviour
- Investigate returns and order performance
- Build an interactive Power BI dashboard
- Produce data-driven business recommendations

## Tools & Technologies

- Python
- Pandas
- SQL
- PostgreSQL
- Power BI
- Git & GitHub
